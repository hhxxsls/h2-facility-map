# Global hydrogen facility inventory — interactive map

Interactive map + statistics for the integrated global hydrogen infrastructure inventory
(15,319 facilities, step 4 integration, 2026-11-08). Built as a single self-contained
`index.html`; the facility table and source list are embedded in the page.

Open it on GitHub Pages: `https://<your-username>.github.io/<repo-name>/`

Data: `facilities_final.csv` and `facility_sources.csv` (not included here); the basemap
(Natural Earth 110m) and D3 load from cdnjs when the page opens.
